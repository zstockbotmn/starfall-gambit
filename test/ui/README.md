Headless UI checks (need `playwright-core` and Google Chrome; run from a folder where playwright-core is installed, e.g. NODE_PATH=/workspace/sg-tools/node_modules).
- `node stress.js <url> [games] [width] [height]` – tap stress test. Phase A: select/destination taps with mixed input (CDP touch, mouse, click-only), drift up to ~0.5 cell, holds, pre-selects and destination taps during the computer's delay (must do nothing, show "Wait for Red's move", no markers/hatching/'!'), taps right after redraws. Phase C (env EDGE, default 60): drift < 0.25 cell across a border, lifts up to 8px outside the board edge, corner taps (rounded corner / up to 6px outside), re-tap of the moved ship at ~160ms (and a ~60ms echo that must be ignored). Phase B (env SWIPES, default 150): swipes/drags that must change nothing. Must report 0 dropped, 0 swipe moves, 0 changes.
- `node shot8.js <url>` – feature/layout checks + screenshots (screenshots/m2/ui) at 390x844, 375x548, 320x460, 320x568.
- `node m2shots.js <url>` – M2 showcase screenshots, reduced-motion check, ship contact sheet and marker sheet (screenshots/m2). Then `python3 contrast.py` prints WCAG contrast of each marker against each square type (sampled from the rendered marker sheet).
The game must be opened with `?debug` (the scripts add it) for the test hooks and the on-screen tap log.
